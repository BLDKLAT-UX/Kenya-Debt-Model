# Kenya Debt Sustainability Analysis (DSA) Model

A full Python-based Debt Sustainability Analysis model for Kenya,
producing an Excel workbook with 8+ analytical sheets, charts,
sensitivity analysis, Monte Carlo projections, and an AI chat assistant.

---

## Files in this project

| File | What it does |
|------|-------------|
| `kenya_debt_model.py` | Builds the full Excel workbook (8 sheets) |
| `charts_excel.py` | Adds a CHARTS sheet with 4 embedded charts |
| `sensitivity.py` | Adds sensitivity analysis tables |
| `pdf_report.py` | Generates a PDF summary report |
| `scenario_export.py` | Exports all scenarios to CSV |
| `debt_projections.py` | Monte Carlo simulation (10,000 runs) |
| `fiscal_space.py` | Fiscal space analysis sheet |
| `summary_report.py` | Prints key DSA indicators to terminal |
| `chat_model.py` | AI chat assistant (ask questions in plain English) |
| `Kenya_Debt_Model.xlsx` | Output workbook (generated by running the scripts) |

---

## How to run

### Requirements
- Python 3.10 or higher (no extra packages needed except openpyxl and reportlab)
- Install dependencies once:
```
pip install openpyxl reportlab
```

### Run in order
```bash
python kenya_debt_model.py       # Step 1 — build the workbook
python charts_excel.py           # Step 2 — add charts
python sensitivity.py            # Step 3 — add sensitivity analysis
python pdf_report.py             # Step 4 — generate PDF report
python scenario_export.py        # Step 5 — export CSV data
python debt_projections.py       # Step 6 — Monte Carlo simulation
```

### AI Chat Assistant
```bash
python chat_model.py
```
Requires a free Google Gemini API key:
1. Go to https://aistudio.google.com/app/apikey
2. Sign in with Google and create a key
3. Create a file called `api_key.txt` in this folder
4. Paste your key as the only line in that file
5. Run `python chat_model.py` and ask questions

Example questions:
- Is Kenya's debt sustainable by 2030?
- Which stress scenario is most dangerous?
- What reforms would bring debt below 55%?
- Summarise the key risks in two sentences

---

## Key findings

- Kenya's Debt/GDP is **63.7%** (FY24/25) — above the 55% IMF/WB anchor
- Debt service is **71.2% of revenue** — more than double the 30% threshold
- Most severe scenario: **Revenue Shortfall** (debt reaches 72.8% by FY29/30)
- Only the **Optimistic scenario** brings debt below the 55% anchor
- Overall DSA rating: **MODERATE-TO-HIGH RISK**
